# v4l2loopback with DMABUF Export

This project is a fork of the widely-used [`umlaeute/v4l2loopback`](https://github.com/umlaeute/v4l2loopback) kernel driver.

This fork is an **experiment** to add support for exporting DMABUF file descriptors via the `VIDIOC_EXPBUF` ioctl to the original driver.

For detailed information please see the documentation:

* [v4l2loopback and DMABUF Documentation](https://github.com/daijh/v4l2_camera/blob/master/doc/v4l2loopback_and_dmabuf.md)

[The original project revision](https://github.com/v4l2loopback/v4l2loopback/tree/8902b3f11413166e7823c377dbf876bae1fab137)
